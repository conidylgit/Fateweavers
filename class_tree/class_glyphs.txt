# FATEWEAVERS - class icons
#
# Every icon is ONE solid black silhouette: the class's path symbol, reshaped.
# Classes that aren't listed here show their plain path symbol (triangle, D, square...).
# Style guide: ICON_STYLE.md in this folder.
#
# ---------------------------------------------------------------------------------
# FORMAT
#   A class id on its own line (ids are in fateweavers_class_tree.json), then one shape per
#   indented line. Shapes are on a 100 x 100 grid: (0,0) top-left, (100,100) bottom-right.
#   Shapes are joined together in order; "cut" carves a shape out instead.
#
#   symbol                         the path's own plain symbol, to build on
#   poly x1 y1 x2 y2 x3 y3 ...     straight-sided shape through the points
#   circle cx cy r
#   ellipse cx cy rx ry
#   rect x y w h [round]           box, optional rounded corners
#   line x1 y1 x2 y2 [width]       thick line with round ends (width default 6)
#   path M x y L x y Q cx cy x y C c1x c1y c2x c2y x y Z
#                                  curves, SVG-style, absolute coordinates only
#                                  (you can paste paths from a drawing app if they use M L H V Q C Z)
#
#   Put these in front of a shape:
#   cut                            carve it out of what's above
#   wire                           only its thick outline (the Light Melee look)
#   stroke W                       only its outline, W thick
#
#   Restart the game to see changes. Mistakes are printed in the run.bat window.
# ---------------------------------------------------------------------------------
